tidepic 을 따르는 컴패니언은 바뀌는 숫자를 화면에 띄워 둘 장면으로 바꾼다. 남은 날은 꽃잎이 되고, 걸음수는 차오르는 물이 되고, 시세는 산악 열차의 기울기가 된다.

이 저장소에는 **tidepic 규칙**이 있다. 컴패니언이 받는 데이터의 모양과, 컴패니언을 꾸리는 규칙이다.

tidepic 은 규칙의 이름이고, [Tidepark](https://tidepark.com)은 이 규칙으로 만든 컴패니언을 모아 보여 주는 곳이다.

- [SPEC.md](SPEC.md) — 규칙 (영문)
- [CHANGELOG.md](CHANGELOG.md) — 바뀐 내용

## 예시 하나로 보는 생각

컴패니언은 작은 JSON 문서를 읽는다. 그 숫자가 무엇을 뜻하는지는 모른다.

```json
{ "spec": 1, "values": [ { "value": 5, "to": 8 } ] }
```

물 여덟 잔 중 다섯 잔이든, 여덟 장 중 다섯 장이든, 여드레 중 닷새든 장면은 같다. 무엇을 뜻하는지는 데이터를 보내는 쪽이 정한다.

## 실행기와 본보기

이 저장소에는 규칙에 적힌 것을 실제로 돌리는 실행기(런타임)도 있다.

- [`runtime/`](runtime)은 피드를 읽어 검사하고, 값을 계산하고, 조건을 판정하고, 컴패니언을 튼다. 컴패니언은 그림 몇 장과 경우표로 만든 것일 수도 있고, 직접 짠 그리기 코드일 수도 있다. 빌드 없이 쓰는 자바스크립트 모듈이고 다른 것에 기대지 않는다. Lottie 파일을 트는 것만 예외여서, `lottie-web` 꾸러미와 번들러가 있어야 한다.
- [`examples/table/`](examples/table)은 경우표와 그림 몇 장으로 만든 컴패니언이다. 그리기 코드가 없다. [tidepic.com/examples/table/](https://tidepic.com/examples/table/)에서 돌고 있다. 주소 끝에 `?v=20&to=100&num=1`을 붙이면 숫자를 줄 수 있다.
- 직접 만들려면 `examples/table/`을 복사해 그림을 바꾸고 `scenes.json`을 고친다. 정적 파일 서버 아무것으로나 그 폴더를 열면 된다.
- `npm test`로 실행기의 테스트를 돌린다.

실행기도 규칙처럼 초안이고 규칙과 함께 바뀐다. tidepark.com 의 컴패니언은 이 저장소에 없다.

## 상태

초안이다. 지금 판은 규칙 첫머리에 있다. 첫 공식 컴패니언들을 이 규칙에 맞춰 만든 뒤 1.0 으로 확정한다.

이 규칙으로 만든 컴패니언은 [tidepark.com/gallery](https://tidepark.com/ko/gallery)에서 볼 수 있다.

피드가 규칙에 맞는지, 컴패니언이 어떤 값으로 그리게 되는지는 [피드 확인기](https://tidepic.com/check.ko.html)에 붙여 넣어 볼 수 있다. 확인기도 같은 실행기를 쓴다.

숫자를 장면으로 보여 주려는 시도는 전부터 있었다. tidepic 은 새로운 생각이 아니라 약속 하나를 적어 둔 것이다. 앞서 있던 것들은 규칙 14절에 적었다.
