# tidepic

**숫자를 차트 대신 장면으로 보여 주기 위한 규칙.**

[English](README.md)

![기울어진 산악열차의 창가. 창밖으로 호수와 설산이 보이고, 손잡이는 똑바로 늘어져 있다.](scene.webp)

이건 주식 데이터일 수도,\
오늘 온도일 수도,\
오늘 몸무게일 수도,\
오늘 걸음수일 수도 있습니다.

그 숫자가 오르면 열차는 오르막을, 내리면 내리막을 탑니다.

tidepic 을 따르는 컴패니언은 살아 있는 숫자를 화면에 띄워 둘 장면으로 바꾼다. 남은 날은 꽃잎이 되고, 걸음수는 차오르는 물이 되고, 시세는 산악 열차의 기울기가 된다.

이 저장소에는 **tidepic 규칙**이 있다. 컴패니언이 받는 데이터의 모양과, 컴패니언을 꾸리는 규칙이다.

tidepic 은 규칙의 이름이고, [Tidepark](https://tidepark.com)은 이 규칙으로 만든 컴패니언을 모아 보여 주는 곳이다.

- [SPEC.ko.md](SPEC.ko.md) — 규칙 (한글)
- [SPEC.md](SPEC.md) — 규칙 (영문)
- [CHANGELOG.md](CHANGELOG.md) — 바뀐 내용

## 예시 하나로 보는 생각

컴패니언은 작은 JSON 문서를 읽는다. 그 숫자가 무엇을 뜻하는지는 모른다.

```json
{ "spec": 1, "values": [ { "value": 5, "high": 8 } ] }
```

물 여덟 잔 중 다섯 잔이든, 여덟 장 중 다섯 장이든, 여드레 중 닷새든 장면은 같다. 무엇을 뜻하는지는 데이터를 보내는 쪽이 정한다.

## 상태

초안 0.1 이다. 첫 공식 컴패니언들을 이 규칙에 맞춰 만든 뒤 1.0 으로 확정한다.

이 규칙으로 만든 컴패니언은 [tidepark.com/gallery](https://tidepark.com/ko/gallery)에서 볼 수 있다.

피드가 규칙에 맞는지, 컴패니언이 어떤 값으로 그리게 되는지는 [피드 확인기](https://tidepic.com/check.ko.html)에 붙여 넣어 볼 수 있다. 확인기가 쓰는 검사와 계산 코드는 [`runtime/`](runtime)에 있다.

숫자를 장면으로 보여 주려는 시도는 전부터 있었다. tidepic 은 새로운 생각이 아니라 약속 하나를 적어 둔 것이다. 앞서 있던 것들은 규칙 14절에 적었다.
